# <> Release 2.21.0 - Premiere CEP Depreciation
With this release, `Premiere` `CEP` functionality is officially depreciated in favour of `UXP`. `After Effects` will continue to use `CEP` until its `UXP` implementation has hit a similar level of implementation as `Premiere`.

## Functions
- ❗ Removed `alwaysOnTop()`, `drawBorder()`
  - Moved functionality into `topBorder {`
  - `topBorder.toggle()` *(replaces `alwaysOnTop()`)* will now ensure the border remains persistent on the selected window, even if the currently focused window changes
- ✏️ Added `onPath()`, `getSystemLocale()`, `topBorder {`
- ✅ Fixed `KSA` not generating hotkeys for the version selected in `settingsGUI()` if multiple versions are installed
- 📋 Added `png`/`jpg`/`jpeg`/`webp` output actions to `ffmpeg().all_XtoY()`
- 📋 `settingsGUI()` will now prompt `Core Functionality.ahk` to regenerate `KSA` when the `Year` version is changed
    - Fixes scripts throwing when reloaded due to `27.0+` pathing changes within the `.kys` files
- 📋 `slack.button()` now makes use of `Toggle()`/`Invoke()`/`Expand()` `UIA` functions instead of relying on `ControlClick()`
- 📋 `rbuttonPrem.movePlayhead()` can now restore the previous `Premiere` sequence order (instead of just the individual sequence) if the active sequence changes during the save
- 📋 Moved `docker {` `Classes\docker.ahk` => `Classes\Apps\docker.ahk`
- 📋 `premUIA_Values {` functions will now automatically attempt to regenerate panel info when necessary (*ie. a panel wasn't visible during initial generation*)
- 📋 `syncDirectories()` now accepts parameter `excludeDirs`
- 📋 `startup()`.`libUpdateCheck()`/`updateAHK()` are no longer influenced by the `update_check` setting and entirely rely on their own settings

### 📝 `prem {`

- 📋 `determineLockedTracks()` can now use `UXP` to return its object in `Premiere` versions greater than `27.1.0`
- 📋 Replaced all usage of `__remoteFunc()` => `__remoteUXP()`
- 📋 `__checkPremRemoteDir()` removed param `cepOrUXP`
- 📋 Will now check the installed version of `Premiere` and present a warning if the installed `Locale` isn't `en_US`

# <> Release 2.21.0.1 - Hotfix
This release is a hotfix for release `2.21.0`<sup>[[changelog]](<https://github.com/Tomshiii/ahk/releases/tag/v2.21.0>)</sup> which was a rather large update and includes the depreciation of the Premiere CEP functions to be replaced with UXP. If you encounter any issues with this update, please be sure to create a [github issue](<https://github.com/Tomshiii/ahk/issues>) to let me know.

> [!Caution]
> `docker` is now *required* for the UXP plugin. The installation of my repo will fail if the user does not first install it.
***

## Functions
- ✏️ Added `CONST {`, `AdobeRemoteUXP {`
- ✅ Fixed `vscode.__isInstalled()` returning false erroneously

### 📝 `prem {`
- ✅ Fixed `isEditTabActive()` failing with windows scale other than `100%`
- 📋 `__remoteUXP()` now runs through `AdobeRemoteUXP.__remoteUXPCore()`
    - Fixed `UXP` `JSON` strings unable to contain `\`

### 📝 `ae {`
- ✏️ Added `__remoteUXP()` which runs through `AdobeRemoteUXP.__remoteUXPCore()`
    - *UXP functionality is only currently available in the `After Effects` 27.1 Beta*
- 📋 Laid groundwork for `UXP` support to transition once publicly available
    - *Full installation processes have not currently been fleshed out*

### 📝 `PremiereRemote`
- ✏️ Added `custom/attachMissingProxies()`
- ✅ Fixed `custom/setZeroPoint()` throwing when already set

## Other Changes
- ✅ Fixed `resetBuild.ahk` always adding a `de.sebinside.premiereremote_3.0.0` folder
- ✅ Fixed issues during installation;
    - Installation will now abort early if `docker` is not installed
    - Installer should no longer get stuck in a state where it fails and then cannot try again
- 📋 Installer will now show more information without throwing if installing `PremiereRemote`/`AERemote` fails

🔗 `install_PremiereRemoteUXP.ahk`
- 📋 Will now prompt the user to close `Premiere` if it is open
- 📋 Will now set required registry values

🔗 `mult-dl.ahk`
###### *(v1.5.3 -> v1.5.4)*
- ✅ Fixed script throwing if `PremiereRemote` wasn't installed
